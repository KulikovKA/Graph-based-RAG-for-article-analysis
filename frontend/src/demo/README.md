# Тестовый граф

Из каталога `frontend`:

```sh
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

Открыть http://127.0.0.1:5174/graph-demo.html.

Страница использует рабочий `GraphExplorer` с вымышленными данными: идея,
три признака, четыре источника, девять связей и по два дополнительных признака
у каждого источника. Docker, учётная запись и модели не требуются.
Подмена API действует только в отдельной точке входа демо. Обычная сборка
приложения использует `index.html` и не включает эту страницу.

- Перетаскивание свободного поля перемещает граф.
- Кнопки `+` и `−` меняют масштаб.
- Нажатие узла показывает детали и подсвечивает путь от идеи.
- «Раскрыть один hop» загружает признаки источника, «Свернуть связи» скрывает их.
- «Открыть цитату» показывает вымышленную цитату под графом.
- «Сбросить вид и связи» восстанавливает исходное состояние.
- На узком экране узлы представлены списком; отдельные узлы мышью не перемещаются.

Проверка: `npm run test:e2e -- graph-demo.spec.ts`.
