# Рубрика 0.3 — единая схема автоматического прохода

Рабочие правила 0.2 сохраняются. Пользователь утвердил Q2/Q3 и разрешил
завершить 24 документа без промежуточных вопросов. Schema approval не означает
проверку labels человеком. Human review остаётся NOT_REVIEWED.

- OPTIMIZES: PROCESS → DEVICE/MATERIAL. Направленная оптимизация объекта;
  неизвестная целевая метрика не подменяется выдуманным performance improvement.
- FACILITATES: MATERIAL/PROCESS → PROCESS. Содействие процессу, без необходимой
  или достаточной причинности и без транзитивного достраивания.
- Всего 18 принятых predicates. После всех 12 DEV зафиксирована однозначная
  временная версия `pilot24-rubric-0.3-AUTO-FROZEN`; SHA-256 записан в
  `../reports/DEV_ONTOLOGY_FREEZE.json`. Первая запись freeze завершилась ошибкой
  файловой системы; вывод CALIBRATION-текста произошёл до повторной успешной записи.
  Определения 18 predicates уже были заданы по DEV и не менялись из-за этих текстов;
  это ограничение хронологии фиксации явно отражено в freeze report.
- Предложения иных predicates или изменений endpoint domains в DEV остаются
  PROPOSED/UNRESOLVED вне accepted assertions. Неизвестные отношения не становятся
  отрицательными примерами. В CALIBRATION/HOLDOUT только регистрируется непокрытие.
- Полный AI draft означает обработку всех предложений и сохранение всех найденных
  кандидатов. exhaustive_relations=false при нерешённых содержательных случаях.
  Это не измеренный recall и не gold.
- Модальность DFT/first-principles исследования сохраняется в scope/qualifiers:
  ASSERTED может обозначать заявленный вычисленный результат, а не эксперимент.
  Prospective/could/may claims сохраняют HYPOTHETICAL, авторские объяснения
  с suggest/propose — PROPOSED. Нет фиксированного default positive для отрицаний.
- Числа сохраняются без преобразований: source spelling, units, analyte и configuration
  привязаны к конкретному assertion. Численные температуры или сравнения не выводятся
  из общих эпитетов best/high/low. Неоднозначные qualifiers сохраняются в вопросах.
- Canonical concepts документно-локальны. SAME требует локального алиаса/явного
  повторения; классы, варианты функционализации, легирования и defects раздельны.
  Группировка triples не удаляет source occurrences и не уравнивает экземпляры.
- Полный source evidence сохраняется. Неподтверждённый логический вывод не добавляется
  ради связности графа. Нет искусственного максимума mentions/assertions.
- HOLDOUT labels, code specifications с ними, review packets и вопросы с их
  evidence сохраняются вне репозитория в закрытом локальном каталоге. В коммит
  входят только допустимые non-holdout артефакты и агрегированные технические counts.

Окончательное человеческое утверждение онтологии и независимая проверка annotations
остаются отдельными будущими шагами. Зафиксированная версия достаточна для
согласованного автоматического прохода с явно указанным непокрытием.
