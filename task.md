# Правило выполнения задач

Источник задач — [TASKS.md](TASKS.md). Брать только задачу, чьи зависимости завершены. После выполнения проверить критерии приёмки и релевантные тесты, обновить статус задачи и зафиксировать изменения отдельным коммитом.

**После каждой завершённой задачи обязательно выполнить push коммита в репозиторий GitHub проекта:** `https://github.com/KulikovKA/Graph-based-RAG-for-article-analysis`. Задача считается завершённой только после успешного push и проверки, что коммит появился в удалённой ветке. Если push не удался, оставить задачу в статусе «ожидает публикации», записать причину и повторить отправку; не отмечать её выполненной.

Не коммитить секреты, локальные данные пользователей, скачанные корпуса, веса моделей, кеши и содержимое баз. Перед push проверить список файлов в коммите.
