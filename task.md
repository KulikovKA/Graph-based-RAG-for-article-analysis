# Правило выполнения задач

Цель проекта — интеллектуальный агент предварительного исследования технических идей по патентам и научным публикациям. Два режима, Knowledge Graph Explorer и Patent Research Assistant, используют общий Hybrid Graph-RAG. Источники, цитаты и выводы привязаны к версиям и provenance. Юридическая патентоспособность вне scope.

Исследования KG, retrieval и агента, бенчмарки и оценка результатов ведутся в [RESEARCH](https://github.com/KulikovKA/Graph-RAG-news-analytics-system-RESEARCH). Общий сервер MLflow развёртывается в MAIN по контракту [RES-EVAL-001](docs/specs/RES-EVAL-001.md). В основной репозиторий поступают утверждённые воспроизводимые компоненты с проверкой совместимости, тестами и эксплуатационной документацией. Целевая схема использует собственный Graph-RAG, Groq для генерации, PostgreSQL для постоянной памяти, Redis для кэша и Airflow для офлайн-обновления. Требования и критерии выпуска закреплены в [окончательном плане](docs/FINAL_PROJECT_PLAN.md).

Новые задачи выполнять по утверждённому [backlog](TASKS.md). Брать только задачу, чьи зависимости завершены. После выполнения проверить критерии приёмки и релевантные тесты, обновить статус задачи и зафиксировать изменения отдельным коммитом. Текст новых документов, комментариев и коммитов писать на русском языке.

**После каждой завершённой задачи обязательно выполнить push коммита в репозиторий GitHub проекта:** `https://github.com/KulikovKA/Graph-based-RAG-for-article-analysis`. Задача считается завершённой только после успешного push и проверки, что коммит появился в удалённой ветке. Если push не удался, оставить задачу в статусе «ожидает публикации», записать причину и повторить отправку; не отмечать её выполненной.

Не коммитить секреты, локальные данные пользователей, скачанные корпуса, веса моделей, кеши и содержимое баз. Перед push проверить список файлов в коммите.
